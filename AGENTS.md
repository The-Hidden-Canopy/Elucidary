# Elucidary workflow

This is the standalone Elucidary project. Do not rename, delete, or rewrite the separate DASRE repository.
Keep the application local-first, with no browser/server requirement. Preserve Apache 2.0, the Open Canopy Contract, NOTICE, and third-party notices.

Use synthetic repositories in tests. Never execute code from repositories being scanned.
Run the full Elucidary unittest suite and package checks before publishing. Describe Windows trusted-input limits, unsigned packaging, and unverified model/platform support accurately.

Retain the internal verifier_lab namespace until a separately tested migration is requested.
Do not publish user workspaces, source caches, private scan results, credentials, or local path inventories.
